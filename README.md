# 女仆建筑 / MaidConstruction

Minecraft Forge 1.20.1 模组。参考机械动力的蓝图，做一张可以反复使用的「图纸」：

**框选记录建筑 → 拿着它投影到任意位置 → 交给车万女仆按图施工。**

---

## 功能

- **框选录制**：拿蓝图点两个角点，把区域内的方块（含朝向、方块实体数据）完整记录下来
- **实时投影**：手持蓝图时，结构以半透明幽灵方块跟着视线显示，已建成的部分自动隐藏
- **任意定位**：右键方块把投影钉在指定位置
- **四向旋转**：右键空气每次旋转 90°
- **蓝图面板**：Shift + 右键空气打开，可拖动查看 3D 预览，按钮式旋转与清空
- **导入导出**：结构与 `.blueprint.nbt` 文件互转，方便备份和分享
- **女仆施工**：女仆会走到结构旁站定，逐块砌完，缺料自动去容器取

---

## 使用方法

合成蓝图（8 张纸 + 玻璃板），然后：

| 操作 | 效果 |
|---|---|
| 空蓝图 + 右键方块 | 选定第一个角点 |
| 空蓝图 + 再右键另一个方块 | 完成框选，服务端扫描并记录 |
| 空蓝图 + Shift + 右键方块 | 清除选点 |
| 蓝图 + 右键方块 | 锚定投影位置 |
| 蓝图 + **右键空气** | **旋转 90°**（0° → 90° → 180° → 270°） |
| 蓝图 + **Shift + 右键空气** | **打开蓝图面板** |

蓝图有两个形态，物品名会跟着变：**空白蓝图** ⇄ **蓝图**。

> 蓝图本身不能一键放置，建造全部由女仆完成。

## 蓝图面板

Shift + 右键空气打开，分三栏：

```
┌──────────────┬──────────────┬──────────────┐
│              │  旋转 90°     │  blueprints  │
│   3D 预览     │  清空锚点     │  目录文件     │
│  （可拖动）   │  清空录制     │  xxx.nbt     │
│              │  导出到文件   │  yyy.nbt     │
│              │  导入选中文件 │              │
│              │  关闭         │              │
└──────────────┴──────────────┴──────────────┘
```

- **3D 预览**：整个结构以等距视角渲染，**按住左键拖动可以转着看**，底部显示尺寸
- **旋转按钮**：和右键空气等效，面板里直接转
- **清空锚点 / 清空录制**：不用再靠组合键
- **导入导出**：纯文件操作，不占剪贴板

## 导入导出

文件放在**游戏目录的 `blueprints/`** 下（会自动创建），扩展名 `.blueprint.nbt`，内容是压缩过的 NBT。

- **导出**：把当前蓝图写成一个带时间戳的文件，不会覆盖之前的导出
- **导入**：右侧列表选中文件 → 点「导入选中文件」

文件可以直接拷给别人，对方丢进自己的 `blueprints/` 就能用。

## 女仆配合

需要安装 [车万女仆（Touhou Little Maid）](https://github.com/TartaricAcid/TouhouLittleMaid) 1.3.0 以上（可选依赖，不装也能正常用蓝图看投影）。

1. 把**已锚定**的蓝图交给女仆——主手、副手、背包任意一处都认
2. 女仆的工作模式切到 **「蓝图施工」**
3. 她会自己走到结构外圈站定，然后开始建造

施工中的表现：

- 每放一块都会**挥手**、**转头看向施工点**，并播放该方块的放置音效
- 材料不够时跑去最近的容器取，箱子会**播放开合动画**
- 站在原地建完整座结构，不会被主人距离打断
- 建完播报一次，蓝图 tooltip 显示 **「目标建筑已完工」**

已完工的蓝图不再复查。想重新开工，**重新右键定位**（或改朝向）即可清掉完工标记。

## 构建

需要 **JDK 17**。

```bash
./gradlew build          # Windows 用 gradlew.bat build
./gradlew runClient      # 启动游戏测试
```

产物在 `build/libs/MaidConstruction-<版本>.jar`。

Java 版本可在 `gradle.properties` 里改 `java_version`（默认 17）。

## 实现要点

- **结构存储**：存在世界存档的 `SavedData` 里（主世界），蓝图物品只存一个 UUID，避免物品 NBT 膨胀
- **摆放顺序**：先完整方块打底，依附类（火把、半砖等）留到下一轮重试，避免放不下去
- **幂等建造**：已和目标状态一致的方块会被跳过，中断、重扫、存档重载都不会破坏已建成部分
- **女仆驱动**：不走车万女仆的 Brain 调度，而是在服务端 tick 里直接查找并驱动，行为可控、出问题能立刻提示
- **防止掉线**：施工期间给女仆开启待命模式，避免她因为离主人太远被拽走或传送
